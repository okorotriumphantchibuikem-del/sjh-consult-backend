Frontend Developer

Technology Company

⌖ Lagos Full Time Mid Level

Job Description

We are looking for a skilled Frontend Developer to join our growing team. You will be responsible for creating responsive, user-friendly and high-quality web applications.

The ideal candidate should have a strong understanding of modern web technologies and be able to work effectively with designers, developers and other members of the team.

Responsibilities

  • Build responsive and interactive websites.
  • Develop reusable frontend components.
  • Work with designers to implement user interfaces.
  • Test and improve website performance.
  • Fix bugs and maintain existing applications.
  • Collaborate with other members of the development team.

Requirements

  • Knowledge of HTML, CSS and JavaScript.
  • Experience building responsive websites.
  • Understanding of modern frontend practices.
  • Good problem-solving skills.
  • Ability to work independently and within a team.

✓ Competitive salary
✓ Professional growth
✓ Flexible environment
✓ Team collaboration
